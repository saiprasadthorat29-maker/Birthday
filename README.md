# Happy Birthday, Gaitri Mam ❤️

A responsive birthday-surprise website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and Marathi birthday message
- `style.css` — responsive styling, colours and animations
- `script.js` — surprise reveal, typewriter effect, petals, cake wish, confetti and music
- `assets/gaitri-mam.jpg` — the portrait photo supplied for this website

## Run locally
1. Extract the ZIP.
2. Keep `index.html`, `style.css`, `script.js` and the `assets` folder together.
3. Open `index.html` in Chrome, Edge or Firefox.

## Replace or add photos
- Replace `assets/gaitri-mam.jpg` with the new photo, keeping exactly the same filename.
- Or change the image path in `index.html` at `src="assets/gaitri-mam.jpg"`.
- To add memory photos, copy image files into `assets/` and add more `<img>` elements in the portrait/gallery area. Use only photos you have permission to share.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `gaitri-mam-birthday`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for the Pages URL to appear.

## Notes
- Background music is an original gentle melody synthesized in the browser. It starts only after the visitor taps the music button, so it does not autoplay.
- The Marathi typeface is loaded from Google Fonts when internet access is available; fallback fonts remain in place.
- No framework or build step is required.
